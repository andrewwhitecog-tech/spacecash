# Security policy

SpaceCash 0.2.x provides the NorthStar Prime integrated, non-monetary
`closed-loop-mainnet` profile and retains the experimental devnet tools. It has
not received an independent production security audit and must not secure
money, custody, exchange value, cash redemption, or any other real-world value.

Please report vulnerabilities privately through GitHub's **Security** tab by opening a private security advisory. Do not include wallet recovery material, credentials, customer data, or working exploits in a public issue.

Maintainers will acknowledge a complete report as capacity allows, reproduce it in an isolated devnet, and coordinate disclosure after a fix is available. There is currently no bug-bounty promise.

Supported line: `0.2.x`.
